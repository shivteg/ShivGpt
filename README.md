# ⚡ ShivGpt (SAI) - Next-Gen AI Chat, Image & Video Platform

A high-performance, ChatGPT-style web interface powered by **ShivGpt (SAI)** with advanced open reasoning models (**Llama 3.3 70B**, **Llama 3.1 8B**, **DeepSeek R1 Distill**), **AI Video Generation**, and **AI Image Generation** (**FLUX.1**, **DALL-E 3**, **SDXL**). Built with Next.js 14, TypeScript, Tailwind CSS, and Lucide Icons.

---

## 🌟 Key Features

- 🎥 **AI Video Generation Studio**: Generate high-definition AI videos & animations directly from prompts or using `/video [prompt]` command.
- 🎨 **AI Image Generation Studio**: Generate high-definition AI artwork directly from prompts or using `/image [prompt]` command.
- ⚡ **Ultra-Fast SAI Inference**: Real-time text responses up to 800+ tokens/sec.
- 🤖 **Multi-Model Selector**: Switch between Meta Llama 3.3 70B, DeepSeek R1, AI Video, FLUX.1 Schnell, DALL-E 3, and SDXL.
- 🎬 **Video & Image Player Tools**: Embedded HTML5 video player, fullscreen preview, one-click MP4 & HD download, prompt history, and copy-link features.
- 🎨 **ChatGPT UI & Dark Mode**: Sleek glassmorphism theme, markdown support, syntax highlighting, and copy-code buttons.
- 📊 **Performance Analytics**: Live tokens/sec counter, completion tokens count, and API latency badges.
- ⚙️ **Customizable Settings**: Set custom API keys for text, image, and video models, system prompts, temperature, max tokens.
- 💬 **Chat Management**: Create new chats, rename threads, clear history, with full `localStorage` persistence.

## 💻 Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/shivteg/ShivGpt.git
cd ShivGpt

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
